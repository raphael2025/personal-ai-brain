# Support

This project is in early development and does not yet provide production support or guaranteed response times.

- For reproducible bugs, open a Bug Report issue.
- For feature proposals, open a Feature Request issue.
- For architecture and research topics, open an issue with alternatives and evidence.
- For security vulnerabilities, follow SECURITY.md and do not publish exploit details publicly.

Please include versions and minimal reproduction steps. Never upload private archives, credentials, access tokens, or sensitive logs.
