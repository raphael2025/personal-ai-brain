# Security Policy

## Scope

Personal AI Brain is intended to process sensitive personal archives. Security and privacy defects are treated as high priority.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is unavailable, contact the repository owner through the contact method listed on the GitHub profile.

Include affected versions/commits, impact, reproduction steps, and any mitigations. Do not attach real personal archives, credentials, or private data.

## Current security posture

This project is in early design. It is not yet suitable for production use or for ingesting sensitive archives. Authentication, authorization, encryption, audit logging, backup/restore, and threat-model validation must be implemented and tested before production deployment.
