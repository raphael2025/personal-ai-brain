# Architecture Decision Records

ADRs record decisions that affect architecture, module boundaries, data contracts, or security posture.

- [0001 — Local-first and source-of-truth boundaries](0001-local-first-and-source-of-truth.md)
- [0002 — Modular monolith with independent workers](0002-modular-monolith-and-workers.md)

New proposals should describe context, options, trade-offs, decision, and consequences. Accepted ADRs may be superseded, but historical records should remain.
